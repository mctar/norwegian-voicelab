# Norsk · Voice Lab

A Norwegian voice workbench: compare recognition, listen to synthesis and try a local customer-service conversation.

[Open the lab](https://mctar.github.io/norwegian-voicelab/). Inference requires a separate lab access key; no key is included in this repository. Audio is processed on Hugin.

This repository contains only the static web interface and its GitHub Pages workflow. The backend is deployed separately. Read [the field notes](web/brief.md) for model choices, research sources and measurement limits.
